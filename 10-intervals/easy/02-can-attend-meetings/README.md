# Can Attend Meetings

## Problem Statement
(Same as Meeting Rooms - check if can attend all meetings)

## Theory & Data Structures

### Sorting
Sort by start time, check for overlaps.

### Time & Space Complexity

#### Approach: Sorting
- **Time Complexity**: O(n log n)
- **Space Complexity**: O(1)

## Solution Approaches

### Approach: Sorting (Optimal)
Same as Meeting Rooms problem.

## Key Takeaways

1. **Sort by start**
2. **Check overlaps**
3. **O(n log n)** solution
